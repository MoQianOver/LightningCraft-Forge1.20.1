本模组为 LightningCraft 的 **1.20.1 移植版**。

## 原模组简介

> 闪电工艺
>
> 据说只有非常勇敢或极其愚蠢的人，才能与自然界最危险的力量之一相抗衡。
> 要掌握如此强大的力量，需要非常专业的工具和机器。
> 这正是 LightningCraft 发挥作用的地方。用闪电的力量制造东西！
